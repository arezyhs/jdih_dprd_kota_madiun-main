Laporan Perbaikan & Penyesuaian Project Flutter JDIH DPRD Kota Madiun

1. Analisis Awal
Melakukan review struktur folder dan file project.
Mengidentifikasi project sebagai aplikasi Flutter multiplatform untuk JDIH DPRD Kota Madiun.

2. Identifikasi Masalah Build
Error build awal: ketidakcocokan versi Gradle dengan Java (Java 21 membutuhkan Gradle minimal 8.4).
Error lanjutan: compileSdkVersion dan targetSdkVersion masih 33, sedangkan dependency membutuhkan minimal 34.
Warning: Versi Android Gradle Plugin (AGP) dan Kotlin terlalu lama.
Error pada package flutter_inappwebview yang tidak kompatibel dengan Flutter dan Android embedding v2.

3. Langkah Perbaikan
a. Update Gradle Wrapper
Mengubah distributionUrl di gradle-wrapper.properties ke:
distributionUrl=https://services.gradle.org/distributions/gradle-8.4-all.zip

b. Update Android Gradle Plugin & Kotlin
Mengubah versi AGP dan Kotlin di build.gradle:
classpath 'com.android.tools.build:gradle:8.2.2'
ext.kotlin_version = '1.8.22'

Mengubah versi plugin di settings.gradle:
id "com.android.application" version "8.2.2" apply false
id "org.jetbrains.kotlin.android" version "1.8.22" apply false

c. Update Konfigurasi SDK
Mengubah compileSdkVersion dan targetSdkVersion di build.gradle ke 34.
Memastikan minSdkVersion minimal 24.

d. Update Dependency Flutter
Mengubah versi package flutter_inappwebview di pubspec.yaml ke versi terbaru:
flutter_inappwebview: ^6.0.0

e. Penyesuaian Kode
Memperbaiki penggunaan URLRequest pada InAppWebView di home.dart agar menggunakan tipe WebUri sesuai versi terbaru package.
f. Sinkronisasi dan Build Ulang
Menjalankan perintah:
flutter clean
flutter pub get
flutter pub upgrade
flutter run

Memastikan aplikasi berjalan tanpa error.

4. Hasil Akhir
Aplikasi berhasil dijalankan di perangkat dengan sistem dan dependency terbaru.
Semua konfigurasi dan dependency sudah kompatibel dengan Flutter, Android SDK, dan Java versi terbaru.
